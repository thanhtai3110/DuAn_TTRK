# JobConnect Frontend

Giao diện React + Tailwind CSS đã kết nối backend Node.js và SQLite.

```sh
npm install
npm run dev
```

`npm run build` tạo bản build trong `dist`.

Chạy cả frontend và backend bằng `npm run dev` tại `D:\tv2`. Nếu chạy frontend riêng, backend cần chạy ở cổng 3001. Các chức năng tài khoản, phân quyền, CV và ứng tuyển sử dụng API và lưu trong SQLite. Xem [README gốc](../README.md) để tạo Admin và kiểm thử Task 8–15.
